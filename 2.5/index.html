تمرين 2.5: الحالة وإعادة العرض

اكتب الحل في exercise.js، واحفظ، وافتح ال Console عشان تشوف ✓ أو ✗ لكل مهمة. ملف التحقق يجرّب حلك على العناصر الي في المربع تحت.

  1. loadTasks() ترجّع المهام المحفوظة بالمفتاح "techpath-tasks"، أو [] إذا ما فيه شيء.
  2. saveTasks() تحفظ tasks بنفس المفتاح.
  3. render() تعرض كل مهمة في li داخل #tasks، مع الكلاس done للمنجزة، وتكتب في #remaining "المتبقي: " وعدد غير المنجزة.
  4. addTask(text) تضيف { text, done: false }، وتحفظ، وتعرض.
  5. toggleTask(index) تقلب done للمهمة رقم index، وتحفظ، وتعرض.

    اضغط على أي مهمة عشان تقلبها منجزة أو لا.

# برنامج «JavaScript وتفاعل الويب»

مستودع تمارين برنامج «JavaScript وتفاعل الويب» من فريق تطوير الويب، ضمن مبادرة TechPath على Pathy.

## الفروع

المستودع مقسوم على فرعين (Branches)، وهذا الفرع (`main`) للتعريف بس:

| الفرع | فيه |
| --- | --- |
| [`practice-labs`](../../tree/practice-labs) | تمارين الدروس، وهنا تحل |
| [`practice-solutions`](../../tree/practice-solutions) | حلول نفس التمارين |

ابدأ من `practice-labs`، وارجع لـ `practice-solutions` بس بعد ما تحاول.

## كيف تنزّل التمارين

عن طريق الـ CLI:
```bash
git clone -b practice-labs https://github.com/Digital-Minds-Initiative/TechPath-JavaScript-Program/
```

أو اختر فرع `practice-labs` من القائمة فوق الملفات، ثم اضغط **Code** ثم **Download ZIP**.

> انتبه: إذا نزّلت ZIP وأنت على فرع `main`، بتنزل هذا الملف بس، بدون التمارين، لكذا لازم تدخل الفروع الباقية وتحملها كل وحدة لحال.

## محتوى البرنامج

1. **أساسيات اللغة:** المتغيرات، والشروط، والتكرار، والدوال، والمصفوفات، والكائنات، وتصحيح الأخطاء.
2. **الصفحة تتفاعل:** ال DOM، والأحداث، والنماذج، و`localStorage`.
3. **البيانات والشبكة:** البرمجة غير المتزامنة، و`fetch`، والأخطاء، وGitHub API، وإرسال البيانات، وال Modules.

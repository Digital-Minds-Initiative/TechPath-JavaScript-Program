# حلول تمارين برنامج «JavaScript وتفاعل الويب»

هذا الفرع فيه حلول تمارين [`practice-labs`](../../tree/practice-labs)، بنفس ترتيب المجلدات: مجلد `1.3` هنا هو حل تمرين الدرس 1.3.

## قبل ما تفتح الحل

- حاول تحل بنفسك أول. قراءة الحل قبل ما تحاول تخليك تحس أنك فاهم، وأنت ما جربت.
- إذا علقت، ارجع للدرس، واقرأ رسالة ✗ في ال Console: غالبًا تقول لك وش الناقص بالضبط.

## كيف تستخدم الحل

- افتح `index.html` في مجلد الدرس عبر Live Server: لازم تطلع كل المهام ✓.
- قارن `exercise.js` هنا بحلك. حلك ممكن يختلف ويكون صح، المهم أن ملف التحقق يقبله.
- لا تنسخ الحل، اكتبه بيدك عشان يثبت عندك.

## مشروع البرنامج

ما فيه حل للمشروع هنا، لأن كل عضو يبنيه على موقعه هو.

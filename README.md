# تمارين برنامج «JavaScript وتفاعل الويب»

هذا المستودع فيه تمارين كل دروس البرنامج. كل مجلد رقمه نفس رقم الدرس، مثلًا مجلد `1.3` هو تمرين الدرس 1.3.

## كيف تبدأ

1. نزّل المستودع: إما `git clone` (إذا أنهيت برنامج Git & GitHub)، أو من زر **Code** ثم **Download ZIP**.
2. افتح مجلد المستودع كامل في VS Code.
3. افتح `index.html` في مجلد الدرس عبر Live Server.
4. افتح DevTools واختر تبويب Console.

## كيف تحل التمرين

- اقرأ المهام في الصفحة نفسها.
- اكتب الحل في `exercise.js`، واحفظ. Live Server بيعيد تحميل الصفحة لحاله.
- ملف `check.js` يفحص حلك ويطبع ✓ أو ✗ لكل مهمة في ال Console، ويكتب النتيجة في الصفحة.
- لا تعدّل `check.js` ولا `index.html`.

## الأمثلة

مجلد `examples` فيه أمثلة الدروس الي تطبّقها مع الشرح خطوة خطوة، وما فيها ملف تحقق. مثلًا `examples/debugging` هو المثال الكامل في الدرس 1.8، وأخطاؤه مقصودة.

## الحلول

الحلول في فرع (Branch) اسمه `solutions`. حاول تحل بنفسك أول، وارجع للحل بس بعد ما تخلص أو إذا علقت فعلًا. قراءة الحل قبل ما تحاول تخليك تحس أنك فاهم، وأنت ما جربت.

## إذا ما ظهر شيء في ال Console

- تأكد أنك فاتح الصفحة عبر Live Server (الرابط يبدأ بـ `http://127.0.0.1`).
- إذا طلع خطأ أحمر، اقرأه: غالبًا في `exercise.js`، واضغط على رقم السطر عشان تروح له.
